# TechCursos

## Descripción del proyecto

TechCursos es un sitio web desarrollado para la asignatura **Aplicaciones Web, Unidad 1**. Su objetivo es presentar cursos tecnológicos de manera clara, organizada y accesible.

El sitio ofrece información sobre cursos de desarrollo web, programación y bases de datos. También incluye secciones sobre metodología de aprendizaje, beneficios y contacto.

## Tecnologías utilizadas

- **HTML5:** estructura semántica del sitio web.
- **CSS3:** estilos visuales y diseño adaptable a diferentes tamaños de pantalla.
- **JavaScript:** filtros interactivos para los cursos y mensaje de confirmación del formulario.

## Características principales

- Diseño adaptable a computadoras, tabletas y teléfonos móviles.
- Navegación por las secciones de la página.
- Catálogo de cursos con filtros por categoría.
- Formulario de contacto con confirmación visual.
- Imágenes con textos alternativos.
- Capturas de pantalla como evidencia del diseño adaptable.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta `TECHCURSOS` en Visual Studio Code.
3. Abre el archivo `index.html` en un navegador web.
